Проблема и её актуальность

📶

Нет связи — нет ИИ

Почти все ИИ-сервисы для учёбы работают через облако. В сельских школах интернет слабый или его нет — эти инструменты там недоступны.

📋

Готовый ответ вместо мышления

Там, где ИИ доступен, ученик часто получает готовый ответ и просто переписывает его.

🔗

Факты без связей

Учебник даёт факты, но почти не тренирует главное умение — понимать причины и последствия.

Цифровое неравенство: городской ученик получает ИИ-наставника, сельский — нет.

Как это работает для ученика

Роль ИИ в решении

1

Подготовка знаний: учитель + ИИ

Нейросеть строит схему причин и следствий из параграфа. Код проверяет каждую связь по цитате из текста. Учитель одобряет — только тогда схема у учеников.

2

Работа в классе — без интернета

Локальная нейросеть на ноутбуке: подсказки по методу Сократа, проверка прогноза словами, советы по карте мыслей, разбор работ для учителя.

Где не ИИ: последствия в симуляции считает прозрачный алгоритм — мгновенно, одинаково, проверяемо. Защита от ошибок: ответы с цитатами из библиотеки, проверка цитат, последнее слово за учителем, режим контрольной без готовых ответов.

Технологии и инструменты

В продукте

  • Qwen (qwen3.5:4b, qwen2.5:3b) через Ollama — нейросеть на ноутбуке, без интернета
  • Claude, GPT, Gemini — по желанию учителя, когда есть интернет
  • Python (только стандартная библиотека) и SQLite: поиск BM25, кэш ответов, работы учеников
  • JavaScript без сборки, офлайн-PWA (Service Worker), своя отрисовка схем в SVG
  • PhET (University of Colorado Boulder, CC BY 4.0) — 34 симуляций + 2 собственных
  • GitHub Pages и GitHub Actions — демо-сайт и автотесты

Генеративный ИИ при разработке

  • Claude Code (модель Claude Opus 5.5, Anthropic) — код сервера и сайта, 56 автотестов, тексты 700 тем библиотеки, задания к лабораториям, документация
  • Команда ставила задачи и принимала решения; каждое изменение проверено автотестами и вручную в браузере
  • Тексты библиотеки, подготовленные с помощью ИИ, перед уроками проверяет учитель-предметник

Для всех детей и безопасно

Доступность

Режим для особых потребностей: крупный шрифт, высокий контраст, цвета для дальтоников (Okabe-Ito), озвучка, без анимаций. Экраны от 320 px.

🔒

Приватность

Вопросы не покидают коробку, аккаунтов нет, статистика для учителя обезличена.

🛡

Честная учёба

Вход учителя по PIN; режим контрольной без готовых ответов проверяет сервер, а не браузер.

Дальше: пилот → казахский язык → готовая коробка на мини-компьютере → учебники программы Казахстана.
